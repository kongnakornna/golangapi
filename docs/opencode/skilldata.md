# ข้อมูลความสามารถของ Agent (skilldata)

เอกสารนี้สรุปตัวตน ความสามารถ และแนวทางปฏิบัติที่ดีที่สุดสำหรับการมอบหมายงานให้กับ
agent เพื่อให้ได้ผลลัพธ์ที่แม่นยำและรวดเร็วที่สุด

## ตัวตนของ Agent

- **เครื่องมือ**: opencode (CLI แบบโต้ตอบ)
- **โมเดล**: big-pickle (OpenAI SDK)
- **ระบบปฏิบัติการ**: Windows (win32) — เชลล์เริ่มต้นคือ PowerShell 5.1

## ความสามารถหลัก

### 1. จัดการโค้ดและไฟล์
- อ่าน / ค้นหา / แก้ไขไฟล์ในโปรเจกต์
- ค้นหาไฟล์ด้วย glob pattern (เช่น `**/*.go`)
- ค้นหาเนื้อหาด้วย regex (เช่น หาคำสั่ง/ฟังก์ชันที่อ้างอิงกัน)

### 2. รันคำสั่งบนเทอร์มินัล (PowerShell)
- คำสั่ง git, build, test, docker, npm และอื่น ๆ
- รองรับการรันหลายคำสั่งพร้อมกัน (parallel) เมื่อไม่ขึ้นต่อกัน
- ใช้ `workdir` เพื่อระบุไดเรกทอรีทำงานแทนการ `cd`

### 3. จัดการ conda environment
- สร้าง / ลบ environment
- ติดตั้ง / ถอนการติดตั้งแพ็กเกจ
- แสดงรายการแพ็กเกจและ environment ที่มีอยู่
- ค้นหาแพ็กเกจจาก Anaconda channels (conda-forge, bioconda, main ฯลฯ)

### 4. ค้นหาข้อมูล
- ค้นหาเอกสารทางการของ Anaconda
- ค้นหาโพสต์ใน community forum ของ Anaconda
- ค้นหาไฟล์/notebooks ในคอลเลกชันส่วนตัว
- ค้นหาเว็บภายนอกเพื่อข้อมูลล่าสุด

### 5. การจัดการงาน
- สร้างรายการงาน (todo list) สำหรับงานหลายขั้นตอน
- รัน sub-agent แบบขนานสำหรับงานซับซ้อน
- ถามคำถามเมื่อข้อมูลไม่ชัดเจนก่อนลงมือทำ

## แนวทางมอบหมายงานเพื่อผลลัพธ์ที่ดีที่สุด

1. **ระบุปลายทางให้ชัดเจน** — บอกไฟล์/เส้นทางเป้าหมาย (เช่น
   `docs\opencode\skilldata.md`) และวัตถุประสงค์ของงาน

2. **ให้บริบทที่เพียงพอ** — หากเป็นโปรเจกต์ที่มีโครงสร้างซับซ้อน ให้ระบุ
   โมดูล/แพ็กเกจที่เกี่ยวข้อง เพื่อให้ agent อ่านไฟล์ที่ถูกต้องก่อนแก้ไข

3. **แบ่งงานเป็นขั้นเล็ก ๆ** — สำหรับงานใหญ่ ให้แบ่งเป็นขั้นตอนย่อย
   (เช่น สร้างไดเรกทอรี → เขียนไฟล์ → ตรวจสอบผลลัพธ์) ซึ่ง agent จะติดตาม
   ผ่าน todo list ได้

4. **ระบุภาษา/รูปแบบผลลัพธ์** — หากต้องการเอกสารเป็นภาษาไทย ให้ระบุไว้
   อย่างชัดเจน

5. **งดการแก้ไขที่ไม่ได้ขอ** — ระบุให้ชัดเจนว่างานใดควรทำแค่ตรวจสอบ
   (read-only) และงานใดสามารถแก้ไขไฟล์ได้

6. **แจ้งวิธีตรวจสอบผลลัพธ์** — เช่น คำสั่ง run test, lint หรือ
   typecheck ที่ควรใช้เพื่อยืนยันว่าการแก้ไขถูกต้อง

## ข้อควรจำ

- agent จะไม่ commit หรือ push โค้ดเว้นแต่ผู้ใช้ขอโดยตรง
- ควรใช้โปรเจกต์นี้ (icmongolang) โดยให้บริบทจาก main.go, go.mod,
  cmd/, internal/, pkg/ เพื่อความแม่นยำในการแก้ไข
